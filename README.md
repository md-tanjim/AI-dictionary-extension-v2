# 🤖 AI Dictionary Browser Extension

An AI-powered browser extension that helps users understand words quickly with definitions, Bangla translations, and pronunciation. It uses the **Google Gemini API** to make looking up words easier and more convenient.

## ✨ Features

- 📖 **AI-Powered Definitions** — Get explanations of words.
- 🇧🇩 **Bangla Translation** — Understand English words through Bangla translations.
- 🔊 **Pronunciation** — Learn how words are pronounced.
- ⌨️ **Keyboard Shortcuts** — Look up words quickly using keyboard shortcuts.
- 🌐 **Browser Extension** — Access dictionary features directly from your browser.

## 🚀 Getting Started

### Prerequisites

- A compatible web browser that supports browser extensions.
- A Google Gemini API key.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/md-tanjim/AI-dictionary-extension-v2.git
   ```

2. Open the project folder in your code editor.
3. Configure your Gemini API key according to the project's code and configuration.
4. Open your browser's extension management page.
5. Enable **Developer mode**.
6. Select **Load unpacked** and choose the project folder containing the extension's manifest file.

## 🔑 API Configuration

This extension uses the Google Gemini API to generate dictionary definitions and Bangla translations.

1. Get an API key from [Google AI Studio](https://aistudio.google.com/apikey).
2. Open the project folder in your code editor.
3. Open the `popup.js` file.
4. Find the API key configuration in the code and replace the placeholder with your own Gemini API key, following the existing code format.
5. Save the file and reload the extension in your browser.
